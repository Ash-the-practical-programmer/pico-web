## Overview

**CPU-First Image Dataset Factory** is a SaaS platform that automates the generation of high-quality, task-specific image datasets for computer vision and AI model training.

Upload folders or buckets of raw images and define recipes (pair, augment, transform, compare, filter, label, chain operations)—the service runs lightweight, GPU-free vision pipelines to auto-generate specialized labeled datasets for any computer vision task including:

- **Change Detection:** Spot-the-difference pairs and before/after sequences for temporal reasoning
- **Visual Puzzles:** ARC-AGI style pattern completion, logic grids, and transformation sequences
- **Object Detection:** Cropped objects with bounding boxes
- **Model Fine-Tuning:** Synthetic training data generation for vision models
- **Quality Assessment:** Quality-scored image rankings and anomaly detection pairs
- **Style & Variation:** Style transfer pairs, procedurally-varied scenes, and visual QA samples
- **Visual Reasoning:** Reference-comparison sets and reasoning benchmarks

The platform returns clean, versioned manifests in multiple formats (JSON, COCO, HuggingFace, Parquet) plus processed assets—so ML teams building vision models for reasoning benchmarks, researchers creating synthetic training corpora, data scientists generating evaluation datasets, or teams fine-tuning multimodal models get 100k–10M+ high-quality, task-specific samples in days without annotation teams, GPU clusters, or custom data pipelines.
